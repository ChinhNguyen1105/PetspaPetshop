# Implement a feature

Trace the requested behavior through the FE service/store/page, module docs and
existing code. List contract, actor, ownership, status and transaction impacts
before editing. Implement the smallest domain-local change, validate inputs,
protect data and add tests. Update docs and run focused tests/build.

Stop and ask when the FE does not establish required fields, permission rules,
state transitions, database design or payment/capacity policy.
